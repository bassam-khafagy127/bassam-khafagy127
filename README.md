## 🧭 About Me

I'm a mobile engineer who owns apps end to end — architecture, features, releases, and the PR queue — across native Android (Kotlin, Jetpack Compose, MVI) and React Native (TypeScript, Expo). As the sole mobile engineer on **TaskedIn** (10K+ downloads, 4.6★), I'm leading its React Native rewrite to bring it to iOS while migrating 150+ of ~180 Android screens from XML to Compose and cutting cold start by **~30%** with Baseline Profiles and R8. I believe in modular, feature-first codebases with enforced boundaries, shared design systems, and performance claims backed by benchmarks — not guesses. I've also built a merchant payments app from scratch that now serves **~300 merchants** across Saudi Arabia.

- 🔭 **Now:** React Native + Expo rewrite of TaskedIn (New Architecture, custom config plugins) and Compose migration of a 90+ module Android codebase
- 🌱 **Exploring:** Kotlin Multiplatform & Compose Multiplatform
- 🌍 **Shipped for:** Egypt 🇪🇬 & Saudi Arabia 🇸🇦 — full Arabic RTL & localization
- ⚡ **Beyond code:** Football player · 10K runner · Anime fan
